# ⚡ Zoho Quick Start (5 Minutes!)

## Best Option for You: Zoho Forms

Since you use **zohomail.in**, Zoho Forms is PERFECT:
- ✅ No coding
- ✅ 5 min setup
- ✅ Auto emails to your Zoho account
- ✅ Auto saves to Zoho Sheet
- ✅ Embed on landing page

---

## 3 Quick Steps

### 1️⃣ Create Zoho Form (2 mins)

```
1. Go to zoho.com/forms
2. Login with your zohomail.in account
3. Click "Create New Form"
4. Add ONE field: Email (type: Email, required)
5. Done!
```

### 2️⃣ Configure Auto-Email (2 mins)

```
1. Settings → Email Notifications
2. Enable "Email form responses to me"
3. Enable "Send confirmation to respondents"
4. Customize email message
5. Click Save
```

### 3️⃣ Embed on Landing Page (1 min)

```
1. Click Share → Embed
2. Copy the code
3. Paste into your landing page
4. Done!
```

---

## Get Embed Code

After creating form, you'll see:

```html
<iframe src="https://forms.zoho.in/f/XXXXX" ...></iframe>
```

That's it! Just embed this on your landing page.
